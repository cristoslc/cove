## Two tooling fixes worth remembering

- **`cove --version` drift.** `__init__.py` hardcoded `0.6.0` while pyproject
  moved — the ADE release would have shipped a CLI that misreported itself.
  Fixed at the root: `importlib.metadata.version("cove-cli")` with a literal
  fallback. Version bumps now touch only `pyproject.toml` (+ the lock's
  self-version, relocked by any `uv run`).
- **uv CLI quirks on this machine:** `uv build --directory cli --out-dir
  X` resolves `X` relative to `--directory` (wheel landed in `cli/cli/dist/`);
  and `uv tool install --force --from <wheel>` demands the package positional
  in this uv version — pass the wheel path directly.

### Deviations / caveats

- **Staging E2E not run.** `scripts/staging/e2e.sh` deploys the branch against
  the local Docker stack and would have disturbed the operator's live Cove
  ingress and running bb. Per the non-negotiable boundary I verified build,
  headless health, and nginx proxying in isolated throwaway containers instead.
  Live `ade.cove` acceptance (the plan's "Done looks like") remains for a
  staging run the orchestrator can schedule.
- Added `ade` to `status.OPTIONAL_SERVICES` (needed so `cove up` reconciles the
  running profile) and a top-level nginx `map` (needed for WebSocket upgrade) —
  both beyond the literal file list but required for the delivered behavior.
- The compose `.env` is rendered first-boot only; existing installs get `ADE_*`
  defaults from compose, consistent with the other optional services.
- No stable `cove` reinstall from this branch; `cli/uv.lock` was already
  modified in the worktree before this sashay and is left unstaged.
